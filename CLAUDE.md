# Волна — персональный агрегатор новостей

## Цель

Локальный сайт (`http://127.0.0.1:8000`) для быстрого чтения главного без шума:
«зашёл — увидел самое важное по своим темам — прочитал — закрыл». Собирает новости
из RSS русскоязычных, англоязычных и казахстанских СМИ, раскладывает по темам,
склеивает дубли, даёт читать статьи внутри сайта без рекламы. Владелец — пользователь
из Казахстана, интерфейс и тексты — на русском.

## Стек и устройство

- Python 3.10+, FastAPI + uvicorn, httpx, feedparser, trafilatura, SQLite (`data/news.db`).
- Фронтенд — один файл `static/index.html` (HTML + CSS + vanilla JS), **без сборки и CDN**
  (кроме шрифта Manrope с Google Fonts — с фолбэком).
- Пользовательские настройки (темы, RU/EN/KZ, тёмная тема, прочитанное, сохранённое,
  скрытые источники) — только в `localStorage` браузера, ключи `volna.*`.

```
mynews/topics.py     каталог тем (ключевые слова) и RSS-лент — источники добавлять сюда
mynews/collector.py  сбор, классификация, склейка дублей, рейтинг, раскладка по секциям
mynews/reader.py     извлечение текста статьи + экстрактивное краткое содержание
mynews/search.py     веб-поиск (DuckDuckGo → Bing RSS, без ключей) и чтение любой ссылки
mynews/server.py     API: /api/news, /api/refresh, /api/article/{id}, /api/search,
                     /api/read, /api/topics, /api/sources, /api/weather + фоновое обновление
static/index.html    весь интерфейс
tools/ux_walkthrough.py, .claude/agents/ux-reviewer.md   агент UX-ревью (/ux-review)
```

## Команды

- Запуск: `python run.py` (Windows: `start.bat` или `py run.py`).
- Тесты: `python -m pytest -q` — держать зелёными; на новую логику бэкенда — тест в
  `tests/test_pipeline.py`.
- UX-проверка: `/ux-review [morning|gamer|investor]` или `python tools/ux_walkthrough.py`.
- Настройки — переменные `MYNEWS_*` или файл `.env` (см. `mynews/config.py`).

## Соглашения

- Весь пользовательский текст — по-русски, с правильным склонением (`plural()` в JS).
- Интерфейс должен работать в светлой и тёмной теме (цвета только через CSS-переменные)
  и на ширине телефона без горизонтальной прокрутки.
- DOM строится через `el()` (без `innerHTML` для данных) — защита от XSS.
- Облачные сессии Claude Code обычно без доступа к сайтам-источникам: проверять UI на
  тестовых данных (сидер в БД + Playwright), реальные ленты проверяет владелец.

## Текущий статус (ноябрь 2026)

Работает:
- ~80 RSS-лент (RU 44, EN 22, KZ 13) + Hacker News; автопоиск RSS по главной сайта,
  несколько запасных адресов на ленту; статус лент в подвале.
- 13 тем (до 12 на главной, сетка в 2 ряда, крестик для удаления, свои темы по
  ключевым словам); переключатель источников RU / EN / KZ.
- Блок «Главное сейчас», сворачиваемые секции «Ещё N», закладки-переходы к темам,
  кнопки «Домой» и «Наверх», виджет «Астана» (время + погода Open-Meteo).
- Широкое окно чтения: сначала полный текст с картинками из статьи (строки «![подпись](url)»
  в кэше, без счётчиков/логотипов), «✨ Кратко» по кнопке; «Также пишут».
- Прочитанное / «Новое с прошлого визита», «Сохранить на потом», скрытие источников.
- Поиск по интернету (Ctrl+K) с чтением результатов внутри сайта.
- Агент UX-ревью для Claude Code (по подписке Pro).

Известные ограничения:
- Часть RSS-адресов не проверена из облака; Rozetked и некоторые KZ-ленты могли не ответить.
- Поиск без ключей может временно упираться в лимиты DuckDuckGo/Bing.
- Краткое содержание экстрактивное (готовые предложения), не пересказ.
- На телефоне кнопки RU/EN/KZ и крестики тем меньше 32 px (нашёл UX-агент).

## Следующие шаги (бэклог владельца)

1. Увеличить мелкие кнопки на телефоне (≥ 40 px зона нажатия).
2. Кнопка «Поделиться» в окне чтения.
3. Горячие клавиши: J/K — следующая/предыдущая новость, Enter — открыть.
4. Компактный вид списком (без картинок).
5. Плашка «Есть N свежих новостей — показать» вместо тихого обновления.
6. Установка на телефон как приложение (PWA).
7. Подготовка к публикации в интернете: лимит на «Обновить», необязательный пароль,
   публичный режим без полного текста статей; инструкция для VPS + Caddy
   (быстрый показ другу — `cloudflared tunnel --url http://localhost:8000`).
8. Telegram-бот с утренней сводкой по темам.
9. По желанию: пересказ через Claude API вместо экстрактивной выжимки.
