# 🌊 Волна — персональный агрегатор новостей

Локальный сайт, который сам собирает новости с русскоязычных и англоязычных сайтов
(Хабр, DTF, StopGame, 3DNews, iXBT, Overclockers, PlayGround, The Verge, Tom's Hardware и др.),
раскладывает их по темам и показывает самое важное за сутки — без рекламы и бесконечной ленты.

Базовые темы: **ИИ**, **Игры**, **Железо**. Кнопка **«+»** добавляет популярные темы
(Космос, Наука, Кино и сериалы, Смартфоны, Программирование, Кибербезопасность, Криптовалюты,
Авто) или **свою тему** по ключевым словам.

## Запуск на Windows (самый простой способ)

1. Установите Python с <https://www.python.org/downloads/> — при установке отметьте
   **«Add python.exe to PATH»**.
2. Скачайте проект и дважды щёлкните **`start.bat`**.

При первом запуске он сам создаст окружение и поставит библиотеки (около минуты), потом
откроет сайт в браузере. Окно с чёрной консолью не закрывайте — это и есть сервер.

## Запуск вручную (Windows / macOS / Linux)

```bash
python -m venv .venv
```
Windows: `.\.venv\Scripts\Activate.ps1` · macOS/Linux: `source .venv/bin/activate`
```bash
pip install -r requirements.txt
```
```bash
python run.py
```

Сайт откроется на <http://127.0.0.1:8000>. Лента обновляется сама раз в 3 часа,
кнопка «Обновить» — принудительно.

## Как это работает

1. **Сбор.** Все RSS-ленты из `mynews/topics.py` читаются параллельно (+ Hacker News).
   Если какая-то лента не отвечает, она просто пропускается — внизу страницы есть
   список «Источники» с отметками, кто ответил.
2. **Темы.** Новость попадает в тему, если пришла из ленты этой темы или если в заголовке
   есть ключевые слова темы («нейросет», «видеокарт», «RTX», «ИИ»…). Одна новость может
   относиться к нескольким темам, но на странице показывается один раз.
3. **Склейка дублей.** Одна и та же новость с разных сайтов (даже на разных языках)
   превращается в одну карточку. Приоритет — у русскоязычного источника, остальные
   видны в окне чтения в блоке «Также пишут».
4. **Рейтинг.** Наверх поднимаются новости, о которых написали несколько сайтов
   (бейдж «🔥 ещё 2 источника»), свежие и обсуждаемые (комментарии на Hacker News).
5. **Режим чтения.** По клику статья скачивается, `trafilatura` вычищает рекламу
   и вёрстку, а блок «Коротко» собирается из 3–5 ключевых предложений — локально,
   без внешних API.

Кнопка «🇷🇺 Только RU» скрывает англоязычные новости. Темы, их порядок и свои темы
сохраняются в браузере (`localStorage`).

## Добавить источник или тему

Всё в одном файле — `mynews/topics.py`:

```python
"games": {
    ...
    "feeds": [
        feed("StopGame", "https://rss.stopgame.ru/rss_news.xml"),
        feed("Мой сайт", "https://example.ru/rss"),   # ← новая лента
    ],
},
```

Новая тема — новый блок в `TOPICS` (название, эмодзи, цвет, ключевые слова, ленты);
она сразу появится в каталоге под кнопкой «+».

## Настройки

Можно задать переменными окружения или строками в файле `.env` в корне проекта:

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `MYNEWS_PORT` | `8000` | Порт |
| `MYNEWS_REFRESH_INTERVAL_HOURS` | `3` | Период фонового обновления |
| `MYNEWS_WINDOW_HOURS` | `36` | Новости за сколько часов показывать |
| `MYNEWS_PER_TOPIC_LIMIT` | `9` | Новостей в теме |
| `MYNEWS_HN` | `1` | Hacker News (`0` — выключить) |
| `MYNEWS_OPEN_BROWSER` | `1` | Открывать браузер при запуске |

## Устройство

```
mynews/topics.py     каталог тем, ключевых слов и RSS-лент
mynews/collector.py  сбор, классификация, склейка дублей, рейтинг, превью
mynews/reader.py     извлечение текста статьи + TL;DR
mynews/db.py         SQLite (data/news.db), одна таблица
mynews/server.py     FastAPI + фоновое обновление
static/index.html    весь интерфейс: HTML + CSS + JS, без сборки
start.bat            запуск двойным кликом на Windows
```

Автозапуск на Linux — `deploy/my-news.service`, Docker — `Dockerfile`.
